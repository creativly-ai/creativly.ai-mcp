# Security

Please report vulnerabilities privately using [GitHub's private vulnerability reporting](https://github.com/creativly-ai/creativly.ai-mcp/security/advisories/new).

Include the affected client, tool or documentation page and redacted steps to reproduce. Do not include OAuth tokens, authorization callbacks, private project data or working signed asset URLs in public issues or pull requests. Never test with someone else's account.

This repository contains guides and configuration examples for the hosted Creativly MCP server. Authenticate through the client's OAuth flow; never commit access tokens to configuration files. If a connection is compromised, revoke it from your Creativly account and reconnect with the intended permissions.
